# 科目表 - 列表查询

## 接口信息

- **接口名称**：科目表 - 列表查询
- **接口地址**：`POST /api/AccType/getlist`

------

## 请求头 (Headers)

| 参数名        | 类型   | 必填 | 说明                      |
| :------------ | :----- | :--- | :------------------------ |
| Content-Type  | string | 是   | 固定为 `application/json` |
| Authorization | string | 是   | 用户认证令牌              |

------

## 请求体 (Body)

### 顶层参数说明

| 字段名      | 类型          | 必填 | 说明                               |
| :---------- | :------------ | :--- | :--------------------------------- |
| SEARCH_INFO | array[object] | 是   | 查询条件数组（具体结构见下方详解） |
| PAGE_INFO   | object        | 是   | 分页信息（见下方说明）             |

------

### PAGE_INFO 参数说明

| 字段         | 类型  | 说明                     |
| :----------- | :---- | :----------------------- |
| PAGE_SIZE    | Int32 | 每页条数（此处为 `200`） |
| CURRENT_PAGE | Int32 | 当前页码（从1开始）      |

### SEARCH_INFO 数组结构详解

该数组是一个**条件组合体**，按索引顺序解析，各元素功能如下：

#### [0] - 展示字段配置

| 字段          | 类型          | 说明                               |
| :------------ | :------------ | :--------------------------------- |
| showBody      | string        | 是否显示明细体，`"F"` 为否         |
| showLadder    | string        | 是否显示阶梯价，`null` 为不启用    |
| showSumField  | string        | 是否显示汇总字段，`null` 为不启用  |
| displayFields | array[string] | 表格需要展示的字段列表             |
| sumFields     | array         | 需要汇总合计的字段（当前为空数组） |

#### [1] - 固定条件配置（当前为空对象）

| 字段         | 类型   | 说明                                    |
| :----------- | :----- | :-------------------------------------- |
| fixCondition | object | 固定条件（当前为 `{}`，无额外固定条件） |

#### [2] - 科目表编号筛选（可选）

| 字段          | 类型    | 说明                                |
| :------------ | :------ | :---------------------------------- |
| field         | string  | 筛选字段名：`TYPE_NO`（科目表代号） |
| operator      | string  | 操作符：`in`（多选）                |
| fieldType     | string  | 字段类型：`string`                  |
| fieldDisabled | boolean | 是否禁用：`false`（可编辑）         |
| value         | string  | 筛选值（传空表示全部）              |

#### [3] - 科目表名称筛选（可选）

| 字段          | 类型    | 说明                               |
| :------------ | :------ | :--------------------------------- |
| field         | string  | 筛选字段名：`NAME`（科目表名称）   |
| operator      | string  | 操作符：`contain`（包含/模糊匹配） |
| fieldType     | string  | 字段类型：`string`                 |
| fieldDisabled | boolean | 是否禁用：`false`（可编辑）        |
| value         | string  | 筛选值（传空表示全部）             |
