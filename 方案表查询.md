# 方案表查询

## 接口信息

- **接口名称**：方案表查询
- **接口地址**：`POST /api/BillCommon/ChkExistsSearchRptBs`

------

## 请求头 (Headers)

| 参数名        | 类型   | 必填 | 说明                      |
| :------------ | :----- | :--- | :------------------------ |
| Content-Type  | string | 是   | 固定为 `application/json` |
| Authorization | string | 是   | 用户认证令牌              |

------

## 请求体 (Body)

该接口请求体为空对象 `{}`，无额外参数。

### 请求示例（JSON）

json

```json
{}
```



## 成功响应 (200 OK)

json

```json
{
    "code": 0,
    "message": "Success",
    "data": "F"
}
```



### 响应字段详细说明

#### 顶层

| 字段    | 类型   | 说明                                                   |
| :------ | :----- | :----------------------------------------------------- |
| code    | Int32  | 状态码：`0` 表示成功                                   |
| message | string | 响应消息                                               |
| data    | string | 是否存在方案数据：`"T"`=有方案数据，`"F"`=没有方案数据 |
